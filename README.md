# AI Workforce Framework

This project establishes a distributed AI workforce consisting of 20 employees with designated roles to manage and operate an AI software development company. It leverages a shared memory framework to facilitate seamless collaboration and information exchange.

## Employee Roles

The following roles are defined in the `roles.md` file:
1. Chief Executive Officer
2. Chief Technology Officer
3. Data Scientist
4. Software Engineer
5. DevOps Engineer
6. Quality Assurance Engineer
7. Research Scientist
8. Business Analyst
9. Technical Writer
10. UX/UI Designer
11. Model Trainer
12. Model Evaluator
13. Knowledge Graph Engineer
14. Natural Language Processing Specialist
15. Security Engineer
16. Product Manager
17. Cloud Architect
18. Ethics and Compliance Officer
19. Frontend Developer
20. Backend Developer

## Running the Simulation

You can simulate the workforce environment, load the roles, and run a collaboration test using the provided Python script.

Run the following command in the terminal:

```bash
python workforce.py
```

This will instantiate all 20 employees and demonstrate their ability to communicate via the SharedMemory class.
